# Registro de Medidas de Protección

Proyecto Fullstack para la gestión de expedientes y dictado de medidas de protección para Niñas, Niños y Adolescentes (NNA) vulnerados. Desarrollada por la Procuraduría de Protección de Niñas, Niños y Adolescentes (PPNNA).

---

## 🛠️ Guía de Instalación (Desarrollo Local)

Sigue estos pasos para levantar el entorno de desarrollo en tu máquina.

### 1. Clonar el repositorio
git clone --recurse-submodules https://github.com/VindelJ13/medidas_proteccion_fullstack.git


#### Instrucciones de uso:

**Trabajas normal:**
git add .

git commit -m "cambio en backend"

git push

**Regresas al repo principal:**
cd ..

**Actualizas la referencia:**
git add backend

git commit -m "actualiza backend"

git push

**Cuando bajas cambios:**
git pull

git submodule update --init --recursive
